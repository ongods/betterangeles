# BetterAngeles Figma Make source

The [BetterAngeles Make project](https://www.figma.com/make/yTEPJsyfvrV2P7TxoGTqQB/betterangeles)
was copied into [betterangeles/](./betterangeles/) on 21 November 2026.
The snapshot contains 24 source and configuration files, three PDFs, and four
image attachments. Figma listed `public/favicon.png` but returned “file not
found” when it was requested. Editor history lives in the linked Make project.

The implemented website runs from the repository root with `npm run dev`.
Its React components use the local service catalogue and government content.
