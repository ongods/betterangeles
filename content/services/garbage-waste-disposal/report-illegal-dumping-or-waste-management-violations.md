# Report illegal dumping or waste management violations — Angeles City

Find the official barangay page for an Angeles City waste complaint.

## Where to start

Contact the barangay responsible for the location using the [Angeles City barangay directory](/services/business/find-your-angeles-city-barangay) and ask for its designated waste-complaint channel. When making a report, provide the location, date and time, description, and any photographs you already have. Ask for a reference number or follow-up instructions if available.

The supplied sources do not identify a verified Angeles waste hotline, complaint form, enforcement timetable, or penalty schedule.

## Source scope

Directory references on this page use official city or DepEd records captured in August 2026. Confirm current service arrangements with the responsible office.
