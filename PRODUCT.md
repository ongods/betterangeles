# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Angeles City residents looking for service requirements, businesses preparing
transactions, and visitors looking for city and cultural information.

## Product Purpose

BetterAngeles helps people find readable service guides, official transaction
destinations, city information, and attributable public records.

## Operating Context

The accepted roadmap is in docs/ROADMAP.md. The user has directed implementation
using the currently available Google Docs and repository evidence, with updates
as additional data becomes available. Source gaps must not stop supported work.

## Capabilities and Constraints

Extend the React/TypeScript/Vite application and its YAML/Markdown loaders.
Preserve reference snapshots and archived PDFs. Publish dates and limitations,
keep unknown fields explicit, and use official portals for transactions.
The project operator and official affiliation are unconfirmed; use community
guide wording. Calendar events and latest news load from the official city's
public APIs. No verified geographic dataset is available.

## Brand Commitments

Keep the BetterAngeles name and extend the existing blue Kapwa interface.
This implementation is an extension, not a redesign.

## Evidence on Hand

The planning Google Doc, its November 7 reference snapshot, the existing Angeles
service guides, archived charters, council evidence, and source manifest.
Map geometry, complete current directories, and reusable dictionary/Kulitan
datasets remain unavailable.

## Accessibility & Inclusion

Support mobile layouts, keyboard operation, readable source labels, accessible
search and filters, and English content. Other languages require reviewed copy.
